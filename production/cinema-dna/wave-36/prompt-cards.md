# 旧 251–257｜宿舍末段的物件和画纸连续性
使用 Cinema DNA 3.2.3 里的空间和状态协议。贴合旧编号的动作/物件不等于沿用原镜机位，旧稿状态和 V10 规划分开列出。

夜窗在宿舍尽头，四组上床下桌，戚禾的固定桌位可因镜头方向出现在画幅不同一边；物体不因此实际换位。桌灯长期位于靠墙深处，冷环境光在通道与窗；台灯暖色只在纸与手，右侧近过道摆手机与银钥。251 针对窗帘并拢、空间孤立的原画版本；252 接另一角透出远处室友，二者不是已验证连剪的同一瞬间。

纸 P1 唯一、旧黄纸横向四折；正面的左半是四块紫窗、窗的右下靠内是小橙红半日，右半是孩童、画架与小凳。镜头不能为了多看画而改变人手拇指、纸张镜像、朝向或取放。背面仅露纸纹，不在本批杜撰文字。手机 F1 和钥匙 S1 位于桌面外沿且与 P1 分开，F1 如无明确历史事实默认熄屏。电脑 L1 只在旧版 253/254/256 内出现。旧 257 的日用钥匙串有两枚银匙、只带一个蓝签，另放一枚铜锁及一把短铜匙；现行 V10 道具定版是单银匙，不能用 257 替换。

| 序号 | 行为与状态 | 机位/用途 |
|---|---|---|
