# 《配钥匙》Cinema DNA 重拍

以 V10 的人物和故事作为现行剪辑底本，按 369 个原图镜号单独建立新版本。原有归档和上一轮重拍不覆盖。旧剧情镜头只复现它原来的动作目的，留作制作历史，不会把已舍弃的动机、道具或开盖结局加回 V10。

方法参考：[Cinema DNA v3.2.3](https://github.com/dacnay816y62-hub/cinema-dna-21x9x3/blob/2ebbbd6afddae8a8a9e417826537418ea71f3c43/SKILL.md)。这里使用《配钥匙》自身的剧本、素材、镜头卡和校验，不分发上游代码、模板、示例图或品牌素材。

- 每一张图服务一个具体信息。画面先交代观众该看哪里、人物怎样回应，再定相机落点、眼线和构图。连续段先定空间与动作轴，保留必要的主镜与正反打，不为了花样强行翻轴。
- 寝室窗光、床下台灯、门厅盖缝、锁摊侧窗都有固定世界位置。视点变化可以改变它们在画面哪一侧，不代表光源移动。保留人物和环境的中间调，不用整片压黑或套单一冷暖滤镜。
- 动作账本记录入镜时状态、可见动作与离镜后状态。参考仅承担指定职责。放下、交接、开箱等变化要经可见证据确认，物件不会在下一镜恢复旧状态。
- 每张 PNG 独立生成、独立复核。画幅保留本片 16:9 原图，构图保护约 2.39:1 的中央宽银幕区域，不加黑边、不拉伸。有主体、手势或道具无法读清的镜头不能计入通过。
- 图像及其焦段描述都是制作参考，不是实拍或视频测试。
