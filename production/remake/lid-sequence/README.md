# 338–341 | 整盖开启至回归现实

- 338：50mm，新构图将人物挪至右下、以近箱与左纵深定高度。白内搭、驼色衣袖。指尖触及折边，尚未开盖。
- 339：27mm，旧门框做左侧前景；人拉到远处的箱堆顶端，双手垂落，折盖为一整块且沿后侧抬起；门无开孔。
- 340：90mm，由侧面轻仰看两眼，暖光只落到眼中及近半侧脸，白闪留在剪辑中做。
- 341：40mm 偏斜俯视，比前版多保留桌沿和寝室纵深；现实盒从一开始就是开的，锁和铜钥匙脱离盒体。画纸图案只作已建立母题的局部回扣，不替代童年画的正反面插镜。

保留为 V08.3 同编号版本备选，不直接替换 V10，须随整段做轴线与动势复核。
