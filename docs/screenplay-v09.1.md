# 《配钥匙》V09.1｜全片台本

现行完整剧本，替代 V09 旧开头。03–08 的时长标注沿用约十分钟叙事的创作规划，不是静帧预演时码。实际剪辑请查 V09.1 时间表，旧版提前认盒、保护既有画作和重复开盖均不用。

开头的戚禾不知道自己想做什么。偶尔描窗影只是无意识动作。开盒取出童画以后，她才想起曾经如何看、如何选；结尾只做自己的第一步。

## 01 冷开｜知道怎么试，不知道为什么试

门厅。戚禾站得很小。下排旧门和成年人同高；远处延伸重复的门，空间仍然封闭。她从已有钥匙里挑一把，插不到底，马上再换一把。没成功。最后一声金属碰木，声先过，切回寝室桌沿的同一串蓝签钥匙。她抬头，刚才伏在题上睡着了。暂不解释门或梦。

## 02 黎明寝室｜别人问的，她都有答案

寝室公灯还没开。走廊有水房声音。戚禾盯着同一页，翻不动，食指推一下折角又放回去。笔沿着落在纸边的窗框影子走了很短的一笔；她甚至没去看这笔像什么。

手机语音响，她很快按播放。家里声音像往常一样，没有吵架。

**妈妈（手机）：** 那个报名表我发你了。今天能填完吧？填好了跟我说一声。你别忘了吃饭。  
**戚禾（回语音，几乎没停）：** 好。

室友拿着保温杯经过。她看了眼桌上的报名页，只是随口一问。

**室友：** 那你呢？毕业想做什么？

戚禾抬起一点头。嘴唇动了，但她没有说「画画」，也没有说「我其实不想报名」。让镜头保留这一阵不知道怎么回答的时间，室友不必帮她填满。接一只没动的手和光标所在的空栏；是犹疑，不是已经有了想往哪里去的判断。页面暂不提交，文字若需辨认只在真实页面或后期完成。

### 白天到晚上｜不是一场哭戏，是一天没有一件事轮到自己

窗边、食堂、长桌，三处不同的光，始终是同一页纸、同一个折角。同学走过，她下意识收膝盖让路；止住一会，手才撑住墙。学校的人仍按自己的速度行动，只有她读的那一行没往下走。食堂不把别人拍成占她便宜的人。距离拉远，窗玻璃照着苍白天光，杯子不再冒气，人都散了，纸还停在那里。

回寝室，给习题腾地方挪旧画框。未拆框背轻碰桌面，一重一轻；不出现钥匙。她重新铺平原来那页。臂肘撑不住，头低下去，再低一点；必须看见闭眼和伏案。至此再切第二次门厅。地摊上锁叩木台的两声收回画框伏笔。开盒前，任何镜头都不要把她剪成准备好了择另一条道路的人。

## 03 第二个梦，只记住一处掉漆｜约 02:35–03:30

**门厅，第二次。** 低木门和那条深地面擦痕都在原处；银匙不必再试一轮。镜头跟她蹲低：右下角有个东西轻轻擦了一下，像指甲划过漆。黑处只露一角暗橄榄色金属，右前沿露出米白色缺痕。戚禾用指尖去触。她看不到整个形状，也看不到门厅顶部。

**宿舍。** 现实里走廊关门让她抬头，不再做第一次那么大的惊醒。她用拇指反复蹭食指，像摸到的还在手上。她的目光落在桌下。从里面主动拉出一只旧物袋，摸过纸、夹子，碰到相同的缺口，她才慢慢把整只盒子拿上桌。观众第一次看清：它是一只小铁盒，前幅正中有小铜挂锁。她试着把盒转向灯，不尝试暴力开启。过一拍看自己的门钥匙。

**顺序：** V07_104 等不露顶的同门墙关系 → **P07** 指尖描过缺漆 → C01 回现实醒来 → A04 手拉出旧物袋 → **P08** 同一方向、同一次指尖位置认出小铁盒。A03 与 B05 不并排重复。旧梦里露出顶缝、醒前现实认盒的镜头均撤。

## 04 校门边配钥匙｜约 03:30–04:35

**校门外，日。** 固定在摊边机器工作高度。上一单的铁屑被刷开；戚禾先等那一下刷完才走近。她把日用钥匙和小铁盒一块摆过去，师傅把它们移开一点分别看。

**戚禾：** 师傅，能照这个配一把吗？  
**师傅：** 这把是门上的。跟小锁不是一套。撬倒是能撬，盒沿会变形。

她手心压住盒边，把快滑到师傅那边的盒子拉了回来。第一次她不说好。

**戚禾：** 那不撬了。

挂锁在木台上磕了两下，第二下特别轻。她原本松开的手又扣住袋绳。只留声音，不要插一张在记忆里重复播放的画框。下一场进门后，她绕过书桌正中直接去拿画框，让这个选择证明她听出了什么。

**顺序：** 优先审组内已有地摊实拍，用 V07_140–150 比对动作、景别和剪点。料不接时只补「护盒拉回＋一重一轻」与必要对白；师傅不展开心理分析，也不凭空交钥匙。

## 05 取钥匙、开真盒、翻画｜约 04:35–05:55

**宿舍，晚。** 戚禾挂大衣，白内搭袖口露出来。铁盒放左，银钥匙落在右边。她拿起旧肖像画框，低头摇一下。先闻其声，后见背板扣片。扣片一挑，一把短铜钥匙从框背滑到她的掌心。画像与铁盒里的童年画必须是两件东西：前者挂在盒外，后者尚没拿到。镜头给观众足够看清这把钥匙和日用银匙有多不同。

挂锁弹开。她把锁连短匙一起卸下，搁在盒前，再把盖掀开。**这是现实全片唯一一次开盒。** 里面没有钥匙，也没有指路的话，是四折旧纸。她摊出正面：小凳、画架、小女孩，四格紫窗，右下一个橙红的半日。等观众认出来，她翻到背面：孩子没对齐的一行字，**「我长大要当画家」**。不要旁白代念，不先让她对着纸哭。照翻纸时台灯扫上来的亮度短白，落到同一纸角年轻时的纹理。

**顺序：** A05 框后铜匙 → B02 小挂锁卸下／实拍开盖补对 → A06 看画正面 → A07 手翻 → B06 手写背面（实物道具或后期文字必须正确）→ 短白 → 童年。撤掉画具盒出钥匙、画正面已经写愿望的旧轴，以及现实时空里任何第二次开盒。

## 06 再看一眼窗｜约 05:55–06:50

**童年，小画室。** 白纸没折过。老师手里还有三张要批的纸，从她面前经过，顺嘴说：「试试蓝一点？」戚禾先拿起大家盘里都有的蓝蜡笔，手停了一下。她抬眼看窗，桌沿正好在小孩的视线下。窗光偏紫，下面压着很小一抹橘红。她把蓝笔放回去，自己捏起那根没人拿过的紫色。

**童年戚禾：** 它现在是紫的。

老师随她往外看了一眼，没有争辩，继续分纸。她伏低一点，从右下给画添一块橙红。不用胜利配乐。动作别快，给她自己看、自己选的时间。紫蜡笔拖过窗格边，声音接一支成人铅笔反复划过同一道蓝线。切门闩发涩。**第三次进门厅是读画后一次主观回返，由纸面的触觉、停笔和目光接过去，不是又睡着。**

**顺序：** V07_187–200 里同纸同光位的童年分镜参考 → **P09** 小孩拿起异色蜡笔（如 B03 保留了孩子抬眼，可当短反打） → 紫色落下 → 从 P10 的成年笔声／停顿接门闩。A08 和 P09 不重复两次「选紫」。

## 07 门还是不开，开口在别处｜约 06:50–08:35

**回到同一座门厅。** 入场先用熟悉的下层木门、同侧墙角和人物比例。戚禾把蓝牌银匙送进最后一扇门，只试一次。钥匙被拧紧的手，切到成年戚禾下意识描过习题边沿的窗影；在熟悉的擦纸声里切到小孩握蓝笔也停住，接着抬眼看窗；再切回成年戚禾，手上的笔终于离纸。**P10 用成年停笔做锚，插的是前面已见的 Q01 和 P09，同动作回忆，不再塞一组新闪回。** 回门厅：摊开手，蓝牌银钥匙落地。她没捡，也第一次不去找下一扇门。眼睛离开门把，顶口极细的光在卷边上移动一点。别把缝拍成已有洞，也不把光当作提示箭头。她得自己穿过房间、观察、找出办法。

第一趟拖小铁盒，走几步换手；第二趟从对侧搬一只，地上留下一块未被鞋磨过的暗色。固定远景回到她最早放箱的地方，第一次只叠少数几只，晃，她取了一只塞回底层；第二次才见高低能踩。宽镜让人看明白箱子从房间不同位置被她搬过来，台阶是十几只小箱堆成，不要一切就变成高台。她站稳，抬起手，指腹一碰整块盖的卷边，马上收回来。

停半拍。上一秒满幅严丝合缝，下一秒整块顶顺着后方那根铰链往后慢慢开。两侧同时进光，没有固定屋顶或另一块门扇；不推很久、不用手托住、不翻越盒沿。切极近的双眼：暖一点的光落进眼里。室友拖椅子的声音在此提前进来，接五帧左右短白。

**顺序：** V07_001／104 锁定空间身份 → **P10** 停笔并回插 Q01・P09 → C06 银钥匙落地 → N01 散箱 → N02 拖箱 → N02B 另一端搬箱 → N03 垒箱后全景 → N04 指腹轻碰 → **N04B 手离开，空半拍** → N05 整盖自行掀起 → N06 双眼 → 短白。N01–N06 一律用正式 V08.3 九镜包中的选定版。原先 V07 袖口被勾和翻箱的支线不回填；不用 V08、V08.1 或 V08.2 同段备选。

## 08 白闪落到已开的小铁盒｜约 08:35–10:00

**宿舍，同一个晚上、同一个桌面。** 白闪一完就接现实铁盒高角度俯视：已经打开的整盖、后铰链、右前角掉漆方向，和门厅大盖属于同一个形状。挂锁与铜匙在盒前；她手边还是刚才翻过的画。不另拍她爬出、不加巨盒外景、不演再醒一次。这一个镜头承担了此前「房间就是盒子」的揭示。椅脚拖地声落定，舍友继续翻页，公灯还没关。

她没有像开头那样开着妈妈的催促语音，再随手回个好。她先拨过去。给双唇刚动要吞回去的时间，但这次她还是说了。

**戚禾：** 妈，报名的事，我想先放一放。  
（对面停着。她没用「没事」把电话挂了。）  
**戚禾：** 我想继续画。我想认真走画画这条路。

不替妈妈给一个立刻同意的答复，也不需要两人吵起来。只停一口气，让这句话被听见。随后她把习题册移到左边。把新本摊到原来放报名电脑的那半边，窗格旧画放手边，不抢镜。回到同一寝室里望向床下桌的视角：开头她只有一页不知为什么一直在做的题；现在公灯亮着，桌上多了一本她自己摊开的画本。第一笔有一点偏，她接着往下画。没有拉远给宿舍欢庆，没有突然辞掉现有一切。笔还在走时切黑。

**顺序：** N07 已开铁盒高角度俯视 → **P11** 房间还亮，主动给妈妈打电话（不再把 A13 备选独立重复） → **P12** 局部落笔 → **P16** 回到开场寝室的观察视角，公灯亮着继续画。若实际新图只含挪本或落笔的一半，从 A14／A15 或同桌位实拍补缺，不能重复她已完成的动作。V07 原来的打字、发出与等消息全部撤掉。

## 摄影与安全

开场以 Q01–Q07 的视角、自然光源与停顿塑造压力；见[素材索引](storyboard-index.md)。

- **全片有三种光，不加三套滤镜。** 校园和寝室是实际窗光、灯管与台灯；童年保留原色蜡笔、带暖的窗光和纸纹；门厅用暗橄榄、低饱和旧木，开盖前只一点窄边光，开盖时才让暖光进入。各入场有一只实物或一个可定位声源接力，不靠烟雾、发光门户或堆字幕。P07／P08 机位贴近同一手指方向；一边允许只见色和缺口，另一边在指尖移动后再从容见到盒子的体量及挂锁。不用全黑、浅景深压掉她需要找到的证据。
- **统一美术。** 橄榄铁盒现实约 24×15×6 cm，前中小铜挂锁，后侧长铰链、前右缺口。超尺度的门厅始终是同一铁盒的内腔：下排木门约成人高，深灰磨痕地面、相同墙角；不因开盖扩大门墙或移动下排门。白内搭和驼色大衣接现有素材，近景道具和袖口不匹配就补对，生成图不能把设计替成新的既成事实。
- **安全拍法。** 演员脚下用稳固低承重台藏在箱堆里，不真踩空箱。顶盖特效用独立受控运动；轻触、空拍和整盖运动分机位做，演员不在重物运行路径下。没到位的组内实拍和音频在时间线明标占位，不以预演充实拍。
- **试剪验收。** 看完开头，观众应能读到「她对别人的问题回答很快，轮到自己就没答案」；不能误读为她早已明确要当画家。其后检查钥匙的来源、第三次门厅没有睡着、现实开盒只有一次、结尾她做了什么。
