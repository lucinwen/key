# 《配钥匙》｜故事主旨和版本说明

**现行创作口径：V09.1。** 这是大学生戚禾关于「我想要什么」的心理短片。放弃的是用别人的答案代替自己的选择，不是把某条路拍成对、另一条路拍成错。

## 故事说的是什么

别人问戚禾，表能不能填完、事能不能帮忙，她几乎立刻就说「好」。但室友问她毕业想做什么，她答不出来。**她是真的不知道，不是早就想当画家却没胆说。** 她只是太习惯先解决别人的问题，已经很久没有听过自己的声音。前段让她无心描一小截窗影就够了，不铺作品集、不写投稿、不制造她早已选好方向的证据。

门厅把这种生活变成了空间：一扇扇门像一份份现成答案。她拿日用钥匙挨个试；门不开，她就换下一扇。直到她从旧肖像画框背后找到短铜匙、亲手打开现实的小铁盒，才看见童年的自己：当时她会抬头看看窗外，再有根据地自己选一种颜色。画背「我长大要当画家」不是命令，而是证据：**原来她有过自己的答案，也可以重新开始回答。**

第三次回到门厅，她没再继续试门，放下日用钥匙，抬头看见原来开口在整块顶盖。她把各处的小箱搬过来，垒出踏阶，指尖轻碰盖沿便收手。顶盖沿后铰链自己打开。切眼睛接光，短白闪，落回现实桌上已经打开的小铁盒。她不往外爬，也不再开一次小盒。那通主动给妈妈打的电话和腾出来的半张桌子，才是这场梦在现实里留下的变化。她不必解决整个未来，先敢说「我想继续画」。

## 版本怎样使用

- **V09.1**：[全片现行台本](screenplay-v09.1.md)，以新版开头和 Q01–Q07 为准；V09 下半片被保留，段 G 改用 Q01 的无心窗影回插。
- **V09**：原有分段并未全部废弃；第二次进入门厅起仍是剪辑底本。旧开场不再作为人物动机依据。
- **V08.3**：整盖高潮九镜是当前版本直接保留的画面。V08–V08.2 中翻越、旧开盖及延伸巨盒外景只作历史稿。
- **V07**：001–300 的分镜素材库，记录多种选择与旧拍法，不等于成片顺序。
- 画面入口见[素材索引](storyboard-index.md)。静帧预演是检查叙事与节奏的工具，不是实拍完成情况。
