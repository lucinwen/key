# 《配钥匙》V09.1｜开场替换台本与摄影方案

**这一版替换 V09 开头，不接在旧开头后面。** 第三段以后继承 V09，唯独后半段原 P04 回插改为 Q01。故事开头戚禾不知道自己想要什么。她的手偶尔会去描窗影；那是一时的注意力，不是她已经在坚持的事业。不能提前让她准备画作投稿、撤回作品、藏着完成的画集，也不能让观众以为她已经选择放弃自己的梦想。开盒之后，她才第一次借童年的经验理解现在的自己。

## 冷开｜知道怎么试，不知道为什么试

门厅。戚禾站得很小。下排旧门和成年人同高；远处延伸重复的门，空间仍然封闭。她从已有钥匙里挑一把，插不到底，马上再换一把。没成功。最后一声金属碰木，声先过，切回寝室桌沿的同一串蓝签钥匙。她抬头，刚才伏在题上睡着了。暂不解释门或梦。

## 黎明寝室｜别人问的，她都有答案

寝室公灯还没开。走廊有水房声音。戚禾盯着同一页，翻不动，食指推一下折角又放回去。笔沿着落在纸边的窗框影子走了很短的一笔；她甚至没去看这笔像什么。

手机语音响，她很快按播放。家里声音像往常一样，没有吵架。

**妈妈（手机）：** 那个报名表我发你了。今天能填完吧？填好了跟我说一声。你别忘了吃饭。  
**戚禾（回语音，几乎没停）：** 好。

室友拿着保温杯经过。她看了眼桌上的报名页，只是随口一问。

**室友：** 那你呢？毕业想做什么？

戚禾抬起一点头。嘴唇动了，但她没有说「画画」，也没有说「我其实不想报名」。让镜头保留这一阵不知道怎么回答的时间，室友不必帮她填满。接一只没动的手和光标所在的空栏；是犹疑，不是已经有了想往哪里去的判断。页面暂不提交，文字若需辨认只在真实页面或后期完成。

## 白天到晚上｜不是一场哭戏，是一天没有一件事轮到自己

窗边、食堂、长桌，三处不同的光，始终是同一页纸、同一个折角。同学走过，她下意识收膝盖让路；止住一会，手才撑住墙。学校的人仍按自己的速度行动，只有她读的那一行没往下走。食堂不把别人拍成占她便宜的人。距离拉远，窗玻璃照着苍白天光，杯子不再冒气，人都散了，纸还停在那里。

回寝室，给习题腾地方挪旧画框。未拆框背轻碰桌面，一重一轻；不出现钥匙。她重新铺平原来那页。臂肘撑不住，头低下去，再低一点；必须看见闭眼和伏案。至此再切第二次门厅。地摊上锁叩木台的两声收回画框伏笔。开盒前，任何镜头都不要把她剪成准备好了择另一条道路的人。

## 摄影设计与查看顺序

| 镜头 | 画面何以有效 | 摄影设计（焦段为现场建议，不是生成图元数据） |
|---|---|---|
| Q01 窗影 | 只给一条无意线，别给一幅本来就想完成的作品。 | 约 55–65 mm 的桌边近摄；窗影、铅笔尖和题页边缘分出三层。纸的颗粒与小面积反光足够，不强加颜色。 |
| Q02 铃声 | 手机侵入原本安静的桌面；没有投稿和完整作品。 | 右侧约 65 mm 侧俯，来自窗和桌灯的光保持方位，移焦方向按临近的手机安排。 |
| Q03 答好 | 反应太熟练，所以这次不能演成挣扎很久。 | 约 50 mm 侧脸，中近景露出手机和唇，但另一侧保留床下冷暗区。手和眼都不要夸张。 |
| Q07 问她自己 | 朋友和她在同一画框；用两者之间的空，让观众等一句没有出现的回答。 | 约 45 mm 坐姿平视，两人分在两侧；中间是冷亮窗格，左侧酒红针织只是很小的色块。自然反差，别给炫光。 |
| Q04 空栏 | 不用文字或音乐宣布她想法；手没有完成那一下。 | 斜贴桌面约 55 mm，手与空栏分别在两个可辨平面；保持键盘和桌的实在透视。 |
| Q05 人走过 | 她让开的动作先于表情，身体随后才承认疲惫。 | 约 50 mm，略侧的走廊中景，保留纵深与前景掠过，不用全虚的校园背景。 |
| Q06 还是这一页 | 摄影机退开，让空桌与还在做题的她同时被看见。 | 约 35 mm 的斜俯较大全景，材料冷而不是灰糊；顶灯只照过纸和桌面，桌长超出人物动作范围。 |

实际拍摄的声音重点是**时差**：第一句「好」接得太快，第二个问题后的空白接得太久。试剪先不要用情绪配乐填这个空。窗、床柱、白针织、蓝签银钥匙、题页折角需保持；室友衣着和电脑页面可用实拍版本锁定。后段 P16 留作「敢在亮着灯时继续画」的结尾，不再说新开头已拍了一场偷偷追梦的同机位对照。

电影摄影方法参照 [Open Film 分镜设计](https://github.com/62656456/ai-film-skills/blob/main/skills/ai-storyboard-director/references/shot-design-engine.md) 与 [光色和成像](https://github.com/62656456/ai-film-skills/blob/main/skills/ai-storyboard-director/references/color-and-image-formation.md)：先确定观众得看见的行为，再改观察距离、光源和构图，不用统一暗滤镜替代情绪。
